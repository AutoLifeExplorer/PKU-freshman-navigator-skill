## 检索原则

- 先查目标院校全称，再结合“国新、国际传播、英文、笔试、面试、夏令营、预推免、简历”等关键词缩小。
- 需要跨校归纳时，记录命中来自哪些文件和章节；相似题目不要误计为同一场考试。
- Markdown 转换可能丢失 Word 版式、表格关系或空白页；需要精确上下文时回看原件。
- 图片转录只覆盖清晰可辨的信息；任何模糊文字以原图为准。
