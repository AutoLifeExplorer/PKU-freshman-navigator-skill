# 新闻传播与国际新闻传播保研手册

仅当请求同时具备两类信号时进入本手册：一类是推免、保研、夏令营、预推免或申请准备；另一类是新闻传播、国际新闻传播、国新或明确的新传院校／方向。一般研究生教务、考研和其他专业升学不走本路由。

先读 [baoyan-sources/index.md](baoyan-sources/index.md)，再按任务只读取所需的一个或两个检索镜像；不要默认载入全部题库。

## 1. 真题查询与比较

先确定院校、学院或方向、年份范围、考核环节、语言和用户希望的结果。条件不全时先给能确认的题目集合，再让用户缩小范围。

- 用文件内检索定位学校、方向、年份以及“中文题／英文题／笔试／面试／简历面”等词。
- 保留原资料的“不确定、可能、回忆不全”等表述，不替资料补全题目。
- 比较只归纳样本中反复出现的题型或能力维度；不得把频次表述为命题概率。
- 每组题目紧跟来源标签，格式为：`【资料：原始文件名，PDF 第 N 页或章节（经验整理／回忆题）】`。
- 同一段连续内容来自同一位置时可共用一个来源标签；跨文件或跨章节时分别标注。

## 2. 备考规划

根据剩余时间、目标院校、申请方向、当前基础和每周可用时间，把资料中的经验建议转成可调整计划。默认覆盖专业理论、研究方法、国际新闻与时政、英语、科研／作品、文书材料和模拟训练，但只保留与用户目标有关的模块。

- 资料中的月份和周期是个人计划样本，不是统一进度要求。
- 当前报名时间、材料要求和考核方式必须检索目标院校当年官方通知；未发布时只给不依赖日期的准备动作。
- 对外传播时政与新闻案例必须使用当前权威来源更新，不沿用旧题库中的人物职务或事件状态。
- 输出优先给当前阶段、下一检查点和可验收产物；不要堆成全年愿望清单。

## 3. 个性化模拟面试

用户未提供简历时，先用通用题或请其提供脱敏后的要点，不要求姓名、学号、电话、证件或完整成绩单。用户提供经历后，从一个经历点向下追问研究问题、方法选择、个人贡献、证据、局限、专业契合与未来计划。

- 一轮只问一题并等待作答；用户明确要求整套题单时才一次列出。
- 每次作答后给“结论是否清楚、证据是否具体、与申请方向是否相关、时间是否合适”四项反馈，再给改写思路或示范。
- 中文与英文训练分别控制表达目标；英文题优先检查信息结构和专业词准确性，不把复杂词汇当作唯一质量标准。
- 不编造用户经历、奖项、论文结果或实习贡献，不替用户掩饰事实缺口。

## 4. 证据与时效

本地资料全部按“经验资料”处理。凡涉及当年招生、报名截止、资格、材料、考核形式、导师信息、时政人物或国际组织成员，转读 [source-policy.md](source-policy.md) 并实际检索当前官方或权威来源。

回答中把两类证据分开：本地资料支持“过去出现过什么、可怎样训练”，当前官方来源支持“今年要求什么、现在应做什么”。找不到当年通知时明确标为未发布或待核验，不以往年时间线补位。

## 5. 边界

- 不预测排名、名额、入营、录取或候补转正结果。
- 不承诺押中原题，不把回忆题包装成完整题库。
- 不替用户提交报名、确认志愿、接受录取或放弃资格。
- 不把一位学长学姐的复习方式写成普遍必需条件。
