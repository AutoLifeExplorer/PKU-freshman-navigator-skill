# 网页端交互与视觉规范

复杂任务才生成页面。页面是增强层，不能取代纯文本答案。

## 触发条件

满足任一项时可自动生成：

- 两个以上硬条件参与地点筛选。
- 三个以上方案需要比较。
- 任务跨越多个时间阶段。
- 用户需要勾选、筛选或导出日历。

单一事实、单一步骤或短规则解释不生成网页。

## 视觉方向：燕园路径签

主题是“新生在陌生校园里找到下一步”，不是招生宣传或官网仿制。

- 石青灰 `#DCE6E3`：页面底色与空间感。
- 纸白 `#F7F8F5`：主要内容面。
- 墨色 `#17231F`：正文与高对比层级。
- 导视红 `#7C2435`：主要动作和选中状态，不等同官方品牌色声明。
- 银杏黄 `#D9A928`：时间节点与提醒。
- 湖蓝 `#2D6274`：来源、核验与次级状态。

显示字体使用系统宋体回退（`STSong`, `Songti SC`, serif），正文使用系统中文黑体回退（`PingFang SC`, `Microsoft YaHei`, sans-serif），时间与状态使用等宽系统字体。不得加载远程字体。

唯一标志性元素是“路径线”：地点卡把三个方案串成路线节点；资源页把开通步骤做成盖章路径；四年雷达把时间节点放在可读时间轴上。不要再叠加无意义渐变、玻璃拟态或大面积装饰图形。

## 页面结构

1. 顶部身份条：学年、场景、核验时间、非官方标记。
2. 首屏结论：30 秒内读完。
3. 主要互动区：筛选、展开或勾选。
4. 下一步：复制地点名、打开官方入口、导出已核实日期。
5. 可折叠证据抽屉。
6. 统一提示。

## 单文件约束

- HTML、CSS、必要 JavaScript 内联，不用 CDN、远程字体、分析脚本或外部前端库。
- 外部请求仅由用户主动点击官方来源或地图入口触发。
- 不在页面中存储姓名、学号、成绩或登录信息。
- JavaScript 关闭时，核心内容仍可阅读；交互按钮失效不得隐藏唯一信息。

## 无障碍与移动端

- 320px 宽度仍能单列阅读，无横向滚动。
- 核心操作使用真实 `button`、`a`、`details/summary` 元素。
- 提供明显键盘焦点，触控目标至少约 44px。
- 颜色不是唯一状态表达；文字标签同步出现。
- 正文对比度至少达到 WCAG AA 的常见要求。
- 支持 `prefers-reduced-motion`，不依赖悬停显示信息。
- 页面语言为 `zh-CN`，标题明确，结构使用语义化标题。

## 文案

按钮写用户能预期的动作，例如“只看可讨论”“复制地点名”“展开官方依据”，不要写“提交”“探索更多”。错误或未知状态直接说明如何核验。
