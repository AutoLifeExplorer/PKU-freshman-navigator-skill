# V3 电脑端工作台与视觉规范

页面是完成任务的工作台，不是回答后的附件。默认终端是电脑端，手机用于查看、提醒、导航、勾选和分享。

## 何时生成工作台

满足任一条件时优先生成交互工作台：

- 修改常见条件可能改变结论。
- 需要比较、资格分支、时间冲突、空间路线或任务进度。
- 需要编辑、预览、复制、导出或外部联动。

单一事实或一步操作使用行动简报，不生成页面。

## 双栏外壳

电脑端采用左侧对话、右侧工作台：

```text
┌──────────────────────────────────────────────────────────────────┐
│ 当前阶段       全局搜索                              个人与来源状态 │
├──────────────────┬───────────────────────────────────────────────┤
│ 对话             │ 任务标题              [转换] [导出] [更多] │
│ 用户目标         │ ┌ 路径脊柱 ─ 当前动作 ─ 下一窗口 ─ 以后 ┐ │
│ 助手解释         │ │            当前主输出工作区             │ │
│ 关键追问         │ └─────────────────────────────────────────┘ │
│ 变化摘要         │ 证据与假设   操作记录   外部联动预览       │
└──────────────────┴───────────────────────────────────────────────┘
```

建议初始比例为 32% / 68%，允许折叠对话。条件变化在工作台原位更新，对话只补一句“什么变了、为什么变”。

## 操作栏

- 只显示情境相关的 3–4 个主要动作，使用“加入日历”“打开地图”“导出 Word”等明确名称。
- “更多”容纳语言转换、版本、低频导出和反馈。
- 外部写入先打开预览；用户可以逐项取消，再一次确认。
- 高风险工作台不得出现“替我办理”“自动填写”或相似暗示。

## 视觉语言：燕园路径签

保留以下令牌：

- `#DCE6E3` 石青灰：环境底色。
- `#F7F8F5` 纸白：主要工作面。
- `#17231F` 墨色：正文与主要结构。
- `#7C2435` 导视红：唯一主行动与当前节点。
- `#D9A928` 银杏黄：时间窗口。
- `#2D6274` 湖蓝：证据与次级状态。

标题与阶段名称使用系统宋体回退；正文和控件使用系统中文黑体回退；时间、状态、版本使用系统等宽字体。不加载远程字体。

标志性元素是“路径脊柱”。它必须编码真实关系：在条件处分叉、等待核验处中断、当前动作处使用导视红、时间窗口处使用银杏黄、证据节点连接湖蓝来源。其他区域保持安静，不做卡片墙、装饰性编号、无意义渐变或漂浮图标。

## 八类结构

- 行动简报：结论与主行动，不强制页面化。
- 决策面板：硬条件过滤 → 首选或匹配 → 条件备选。
- 地图与路线：起点 → 路径 → 到达后动作。
- 流程向导：结论 → 适用条件 → 当前动作 → 核验节点。
- 时间工作台：现在 → 下一窗口 → 以后。
- 清单与进度板：待完成 → 当前阻塞 → 已完成。
- 可编辑成果：预览 → 待补字段 → 导出。
- 传播与辅助媒体：受众 → 脱敏预览 → 生成。

不同结构共享视觉语义，但不得强行使用相同页面形状。

## 风险自适应

- 日常探索与分享可以使用校园插画和轻量动效。
- 学业、制度和正式办理降低装饰，突出字段、差异和来源。
- 健康、安全与紧急页面移除非必要动画和品牌叙事，只保留分流与行动。

## 单文件与降级

- HTML、CSS 和必要 JavaScript 全部内联，不用 CDN、远程字体、分析脚本、外部库或浏览器存储。
- 外部请求只由用户主动点击官方、地图或导出入口触发。
- JavaScript 关闭时，结论、核心理由、当前动作和证据仍可阅读。
- 断网时只展示已有快照，并明确核验时间；V3 不承诺离线完整可用。

## 无障碍与多设备

- 桌面至少验证 1440 × 1000；同时保证 390px 和 320px 无横向滚动。
- 真实使用 `button`、`a`、`input`、`dialog`、`details/summary` 等语义元素。
- 键盘焦点清晰，触控目标约 44px；重要操作不设置过短超时。
- 状态必须有文字，不能只靠颜色、运动或空间位置。
- 正文对比度达到常见 WCAG AA 要求。
- 支持 `prefers-reduced-motion`，图表提供文字等价内容，音视频提供字幕或文字稿。
- 页面使用 `lang="zh-CN"`、语义标题和明确的页面标题。
