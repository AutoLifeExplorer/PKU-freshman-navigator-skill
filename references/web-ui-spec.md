# V2 交互与视觉规范

页面不是答案的附件，而是用户完成比较、筛选或规划的工作台。对话只保留首选与入口。

## 自动触发

满足一项即生成页面：

- 改变一个条件可能改变首选；
- 至少 3 个对象需要比较；
- 至少 4 个时间节点；
- 至少 5 个可执行任务；
- 需要筛选、勾选、复制或导出。

单一事实、单一步骤或一张小表已经足够时，不生成页面。

## 视觉语言：燕园路径签

主题是“在陌生校园里迅速找到下一步”。保留以下令牌：

- `#DCE6E3` 石青灰：环境底色。
- `#F7F8F5` 纸白：主要工作面。
- `#17231F` 墨色：正文。
- `#7C2435` 导视红：唯一主行动与当前节点。
- `#D9A928` 银杏黄：时间窗口。
- `#2D6274` 湖蓝：证据与次级状态。

显示文字使用系统宋体回退，正文使用系统中文黑体回退，状态与时间使用系统等宽字体。不得加载远程字体。

标志性元素是“路径线”，且必须表达真实结构：

- 地点页：硬条件淘汰 → 首选 → 条件备选。
- 资源页：未开通 → 操作 → 已解锁。
- 制度页：结论 → 适用条件 → 当前动作。
- 规划页：现在 → 下一窗口 → 以后。

不要把路径线当装饰，也不要把四类页面都做成卡片墙。大胆之处只放在路径交互，其他区域保持安静、清晰。

## 首屏

320px 宽度下也必须在首屏看见：

1. 一个清楚的首选或核心结论；
2. 支撑结论的核心理由；
3. 一个立即动作；
4. 必要时，会改变结论的重要条件。

首屏突出重点，不按固定字数或视觉单元强行截断内容。来源详情、完整比较和次要信息进入后续层级。按钮使用可预期的动作名称，如“复制地点”“只看已核实”“加入日历”。

## 四类结构

- 地点：纵向排序路径；硬条件切换后首选同步变化。
- 资源：可勾选解锁面板；展示当前最值得开的下一项。
- 制度：可回答“这条是否适用于我”的条件流程。
- 规划：聚焦当前节点的时间轴；可展开未来阶段和导出已核实日期。

## 单文件与降级

- HTML、CSS、必要 JavaScript 全部内联，不用 CDN、远程字体、分析脚本、外部库或浏览器存储。
- 外部请求只由用户主动点击官方入口或地图入口触发。
- JavaScript 关闭时，首选、核心动作和证据仍可阅读。
- 页面可以承载唯一完整答案；用户明确要求时再提供纯文本等价版。

## 无障碍与移动端

- 320px 宽度无横向滚动；触控目标至少约 44px。
- 使用真实的 `button`、`a`、`input`、`details/summary`，键盘焦点清晰。
- 状态必须同时显示文字，不能只靠颜色或符号。
- 正文对比度达到常见 WCAG AA 要求。
- 支持 `prefers-reduced-motion`，不依赖悬停显示唯一信息。
- 页面使用 `lang="zh-CN"`、语义化标题和明确标题。
