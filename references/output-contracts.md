# 输出契约

这些是信息字段，不是必须逐字复刻的文案模板。保持首屏简短，并根据证据删去无法支持的字段。

## 共同开头

`本次按 YYYY—YYYY 学年检索 · 身份/院系（如已知） · 更新时间`

随后用一句话给出结论。不要先放免责声明。

## 三选一地点决策卡

每张卡包含：

- 角色：最稳妥／最近／低拥挤风险。
- 地点与一句选择理由。
- 距离或“待地图核验”。
- 插座：确认／经验／未知。
- 声音：安静／可低声／可讨论／未知。
- 剩余开放时间或“待核验”。
- 风险与 Plan B。
- 证据标签：官方／经验、日期、可信度。

先过滤硬条件，不允许把不满足“必须插电”的地点排进前三后再用小字解释。

## 资源解锁清单

分组：现在就开通、需要时再办、仅特定人群。每项包含：

- `免费`、`条件免费` 或 `并非免费`。
- 能解决的具体任务。
- 适用人群与账号/网络条件。
- 2—4 步开通路径。
- 失效或迁移提醒。
- 官方入口和核验日期。

## 制度翻译卡

固定阅读顺序：

1. 官方结论。
2. 这对你意味着什么。
3. 现在做什么。
4. 哪些部分因院系/学年不同而变化。
5. 官方依据。

## 四年雷达

时间层级：现在／本学期／本学年／以后关注。每一节点包含：行动、触发时间、错过风险、依据状态。禁止把所有任务都标成“紧急”。

允许生成：

- 已核实精确日期的 `.ics` 日历事件。
- 无精确日期的观察清单，不生成虚假截止日。

## 新生任务包

按“今天／本周／本学期”组织，每组不超过五项。每项以动词开头，并附完成标准和官方入口。若任务依赖未知规则，先写核验动作而不是猜测结果。

## 证据抽屉与末尾提示

正文关键结论使用轻量编号 `[1]`。结尾按以下顺序：

1. 官方依据。
2. 经验依据。
3. 信息更新时间。
4. 场景化统一提示。

官方依据列：发布者、标题、发布日期、适用学年、链接。经验依据列：来源主体、观察/发布日期、可信度、链接或“用户观察”。
